# contrib — the rest of the desktop

wafflebar themes the bar. These are the pieces that make the *windows around it* match, and the
piece that keeps the displays in order. Nothing here is compiled into wafflebar; it is configuration
for other programs, installed by `scripts/install-desktop.sh`.

| Path | What it is | Where it lands |
|---|---|---|
| `desktop/gtk-3.0/`, `desktop/gtk-4.0/` | the Workbench/CDE bevel grammar for GTK apps, plus font/animation settings | `~/.config/gtk-3.0/`, `~/.config/gtk-4.0/` |
| `desktop/Xresources` | X11 / XWayland app colours and the Xft font | `~/.Xresources` (load with `xrdb -merge`) |
| `desktop/dwl-colors.h` | dwl border colours + width, as a snippet | paste into dwl's `config.h` (natewm-asm owns that file) |
| `monitors/wb-monitors` | deterministic display ordering by EDID identity | `~/.local/bin/wb-monitors` |
| `monitors/monitors.toml.example` | the ranked display list | `~/.config/wafflebar/monitors.toml` |
| `monitors/wb-monitors.service` | systemd user unit running `--watch` | `~/.config/systemd/user/` |

## Qt apps

Not shipped as a file, because Qt's config is generated by a tool rather than hand-written. Install
`qt5ct`/`qt6ct`, set `QT_QPA_PLATFORMTHEME=qt5ct`, pick the **Fusion** style, and set the palette
from the same hexes: window `#a0a0a0`, base `#8c8c8c`, text `#000000`, highlight `#6688bb`,
highlighted text `#ffffff`, and the font to Tengoku 9. (CDE palette: `#aeb2c3` / `#9296a8` /
`#a83e7a`.)

## What will not obey

libadwaita apps ignore user themes for their own widgets — GNOME Text Editor, Files, Settings and
friends keep their round corners whatever is in `gtk-4.0/gtk.css`. That is libadwaita policy. The
options are to use a GTK3/plain-GTK4 equivalent app, or to accept the inconsistency; there is no
config that overrides it.
